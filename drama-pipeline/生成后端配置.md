## 通道 1 · 云 API（出片最快，效果优先）

| 用途 | 首选 | 说明 |
|---|---|---|
| 角色/场景资产生图（组图一致性） | **Seedream 4.0**（火山引擎） | 组图生成带主体一致性，一次出整套分镜参考图；④K |
| 改姿势/换装/多轮编辑 | **Nano Banana**（Gemini 2.5 Flash Image） | 多轮对话式编辑，同人新姿势的事实标准 |
| 生视频（首尾帧续接） | **Kling**（`tail_image_url`）或 **Seedance**（火山引擎） | 首尾帧 API 链式续接；Seedance 原生多镜头提示词（Shot 1/Shot 2）适合 ≤10s 序列 |
| TTS 多角色配音 | IndexTTS-2.5（情绪最强）或 CosyVoice3（Apache-2.0，有 FastAPI/vLLM 部署）或 GPT-SoVITS api_v2 | 部署在一台带卡远程机；纯 CPU 过渡用 edge-tts |
| BGM | ACE-Step-1.5（REST API :8001，<4GB 显存）或曲库 | 中文歌词支持 |
| 音效 | MMAudio（视频→同步音效，有官方 MCP server） | |
| 字幕 | FunASR：`funasr audio.wav --output-format srt`（带时间戳标点，OpenAI 兼容端点） | 中文 CER 显著低于 Whisper |
| 口型（真人剧） | Kling API 口型 > InfiniteTalk（开源无限时长）> LatentSync 1.6（本地最佳中文） | |
| 超分 | SeedVR2（免费，ComfyUI 原生） | 成片最后一道 |

**火山引擎一个账号覆盖 Seedream 4 + Seedance + 豆包 LLM**，是云通道的最小账号集；Kling 可选。

## 通道 2 · 远程 ComfyUI（可控性最强，资产与特效兜底）

租一台云 GPU（≥16GB）装 ComfyUI + 以下插件/模型，本机用 OpenMontage `client.py`（已有）提交工作流：

| 组件 | 用途 | 来源 |
|---|---|---|
| ComfyUI-WanVideoWrapper | Wan2.2 I2V/FLF2V/Animate 运行时 | `_upgrade/ComfyUI-WanVideoWrapper/` |
| Wan2.2 FLF2V / Animate / S2V 官方工作流 JSON | 直接下载参数化，替代坏的 image-to-video.json | https://docs.comfy.org/tutorials/video/wan/wan2_2 及同目录 wan2-2-animate、wan2-2-s2v |
| Wan2.2-Fun InP | 阿里 PAI 首尾帧备选 | https://docs.comfy.org/tutorials/video/wan/wan2-2-fun-inp |
| Index-anisora V3.2 | 动漫专精：任意首/中/尾帧插值、360° 角色旋转 | `_upgrade/Index-anisora/` |
| Qwen-Image-Edit-2511 | 开源一致性之王：主体保持编辑+多人合影（DiffSynth 4GB 可跑） | https://github.com/QwenLM/Qwen-Image |
| 角色三视图工作流合集 | 资产阶段 | https://github.com/yolain/ComfyUI-Yolain-Workflows |
| SeedVR2 | 超分 | https://docs.comfy.org/tutorials/utility/seedvr2 |
| comfyui-api（可选） | 把 ComfyUI 包成无状态 OpenAPI REST | `_upgrade/comfyui-api/` |

**分工建议**：一致性要求高的资产图与特殊镜头走 ComfyUI（Qwen-Image-Edit / AniSora），批量常规镜头走云 API。UHD：`_upgrade/drama-skills` 的 produce 技能对后端是透明的，写好提示词后由 produce 步骤选择通道。
