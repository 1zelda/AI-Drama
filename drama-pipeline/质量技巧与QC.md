# 质量技巧与 QC — 产出任何提示词/分镜前必读

> 来源：英文 BigPromptHub 五件套 QC 体系 + AutoWeeb + RAVE 论文 + 中文 OnlyShot/showvi/drama-skills 实战，四路调研交叉验证（2026-09）。

## 一、QC 五件套（每集必建，缺一不放行）

| 件 | 内容 |
|---|---|
| 选角圣经（casting bible） | 锁定字段：脸型/发型/剪影/服装层/标志道具/情绪基线。锁定字段一经验收**逐字冻结** |
| 参考包（reference pack） | 多角度参考图（正/侧/2/3 侧，脸部+全身），任何分镜前生成并验收 |
| 镜头交接单（shot handoff sheet） | 每镜头分两栏：**锁定身份字段**（逐字复制）+ **场景可变字段**（只动机位/动作） |
| 漂移日志（drift log） | 每镜头按 脸/发/剪影/服装/道具/光/切点 七项对照参考包打分：pass / 小修 / 重生成 |
| 单集验收记录（acceptance record） | 身份漂移未批、转场断裂、字幕不可读 → 阻断放行 |

与 showvi 的「实体状态跟踪」互补：**道具/伤妆/服装等跨镜状态变化必须记进状态表**（如「第 3 镜后左手缠绷带」），下一镜提示词自动带上，避免静默改设定。

## 二、一致性生成技巧

1. **九宫格关键帧法**：同一角色 9-16 关键帧塞进**一张零边距网格图**一次生成，再裁切逐格使用——全部姿势来自同一次生成，一致性天然保住；网格图可再喂 I2V/EbSynth 传播。
2. **锁定名词串**：固定描述串（「银发、钢灰瞳、红围巾、冷蓝调」）在每条提示词逐字粘贴；换装只能由剧情标记触发表记录变更。
3. **窄重生成**：修漂移时锁定字段原样重复，只删漂移因子；**绝不重写整段提示词**。
4. **双主角防融合**：参考包分开、剪影刻意差异化、先出单人特写再出同框镜头。
5. **尾帧三用**：每条片段尾帧 = 缩略图源 + 下一镜设计参照 + 首尾帧续接输入，一次产出三处复用。

## 三、视频提示词技巧

6. **一片段一动词**：一条运动提示词只放一个动作动词（「雨变大。她跪下。」）；一拍三个小动作 > 一个复杂动作。
7. **Seedance 原生多镜头语法**：`Shot 1:… Shot 2:…` 单条提示词内稳定转场，≤10s 序列比首尾帧链省成本。
8. **Seedance 分镜图陷阱**：喂精修分镜图它会把分镜图本身当画面动起来——给草图或纯文字描述。
9. **首尾帧续接**：片段 N 尾帧 → 片段 N+1 首帧（Kling `tail_image_url` / Wan2.2 FLF2V）。
10. **运镜公式**：`[运镜]+[场景]+[动作]+[细节]`；推镜需背景纵深线索，否则主体畸变。
11. **I2V 防融化三条（实战教训 2026-09-09 元首漫剧）**：① 底图里不能有前景遮挡物（半只手、边缘乐器），运动模型会把它们放大成怪物；② 运动提示词严格「一片段一动词」——写明「固定机位、人物保持静止、只有 X 微动、其余完全静止」，塞五个动作 = 脸和组织融化；③ 免费轻量模型（cogvideox-flash 级）人物保持力弱，正脸特写+极简运动是唯一稳定解；静态感镜头直接 Ken Burns 缓推兜底（零变形）。
12. **去水印的正确姿势（实战+调研 2026-09-09，重要度递减）**：① **源头关闭**——智谱视频 API 传 `watermark_enabled=false`（已接入 ZhipuVideoProvider），即梦客户端有「AI生成水印设置」开关：90% 的去水印需求应在这一步消失；② 已知供应商固定角标 → **固定区域+小范围修复**是社区共识（豆包/Gemini 去除器全这么做，通用检测模型反而漏检半透明角标）；用 LaMa 时**大上下文是生命线**（mask 外扩 2.5 倍喂入，小裁剪=灰补丁）；③ 来源不明素材 → 接入 YaoFANGUK/video-subtitle-remover（Apache-2.0，12.8k star，检测+LAMA/STTN，支持固定坐标模式零检测开销；需 Python 3.12 或 paddle≥3.1）；④ 不建议为角标自训检测模型。已沉淀 `backend/app/providers/watermark.py`（三模式：text 白字检测/rect 整块/static 时域中值，供应商预设 zhipu/zhipu_video/agnes）。合规提醒：《AI 生成合成内容标识办法》要求发布内容带标识，去水印仅限制作环节素材净化。

## 四、流程与成本

11. **先关键帧后视频**：每镜头先出 1-4 候选关键帧，人工/Agent 审批后再生成视频——返工成本约 1/18。
12. **抽卡率真相**：5-20 次生成出 1 个可用镜头，实际成本是标价 3-10 倍。预算按此乘数核算。
13. **审核拦截预案**：即梦/Seedance 内容审核拒绝时用提示词中和重写（参考 `Pixelle-Video` 实现、OnlyShot《jimeng-failure-modes.md》17 种故障模式）。
14. **截图反推**：想要某参考视频的风格，截一帧让 LLM 反写提示词，快速对齐。
15. **服装漂移修复**：补具体衣物层+标志物并删冲突风格词，不要整体重摇。

## 五、落地位置

- QC 五件套的状态文件由技能 `short-drama-assets`（连续性记录）和 `short-drama-review`（验收）维护。
